# Лендінг: акумуляторний LED-світильник Svitlo Plaza

Односторінковий mobile-first сайт для продажу одного товару. Статус: збір вимог.

## Факти з упаковки (джерело: Світлоплаза_розгортка.pdf)
- Модель на енергоетикетці: CLFLAL-60A2; довжина 60 см (підтверджено власником; креслення на коробці 300 мм — помилкове), профіль 39 × 9 мм
- Світловий потік 140 лм, потужність 3 Вт, CRI ≥85, кут 120°, IP20
- Колірна температура: 2700/3500/4500/5000/6500 K; яскравість 5–100 %
- Акумулятор 3,7 В 1000 mAh, заряджання USB Type-C, 2–4 год
- Робота: постійне світіння 3–7 год; режим датчика ~2–3 міс.
- Датчик руху + датчик освітленості; режими: постійне, нічний, цілодобовий
- Кріплення: магніт, клейка основа, як ручний ліхтарик; пульт ДК
- Строк служби 25 000 год (L70 B50); гарантія 1 рік; CE, RoHS

## Рішення
- Джерело істини — розгортка коробки (крім довжини: 60 см). Дані сайту виробника не використовуємо.
- Ціна 550 грн. Оплата: накладений платіж або реквізити в месенджер клієнта.
- Доставка: тільки Нова пошта, за рахунок клієнта. Повернення 14 днів, гарантія 1 рік.
- Форма: телефон (обов'язково), відділення НП (необов'язково). Сповіщення адміну в Telegram з джерелом трафіку (UTM).
- Хостинг: Cloudflare Pages (безкоштовно), піддомен svitloplaza.store.
- Контакти: Telegram, Viber, адреса магазину. Відгуків не буде.
- Фото: тільки виробника, без логотипу AIER, з українськими підписами в стилі бренду.

## Структура
- `public/` — сайт (index.html, assets). Cloudflare Pages: build output = `public`.
- `functions/api/order.js` — прийом замовлень → Telegram (змінні TG_TOKEN, TG_CHAT_ID).
- `tools/build_img.py` — обробка фото виробника (запуск з кореня: `python3 tools/build_img.py`).
- Пікселі: заповнити `CFG` на початку скрипта в `public/index.html`.

## Розгортання
- Cloudflare Pages, проєкт `svitlo-light` → https://svitlo-light.pages.dev
- Деплой (direct upload): `wrangler pages deploy public --project-name svitlo-light --branch main` з кореня репозиторію (папка `functions/` підхоплюється автоматично).
- Секрети проєкту: `TG_TOKEN` (бот @SvitloPlaza_bot), `TG_CHAT_ID`.
- Бот також підключений до SalesDrive через webhook — не видаляти webhook (сайт використовує лише sendMessage).
